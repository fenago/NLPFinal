Which library made each result?
  • NLTK Tokenizing, VADER sentiment, word counts and key phrases. Runs in the Netlify build and live in your browser.
  • spaCy Named entities (people, places, brands, products), noun-chunk aspects and the dependency parse. Runs only in the Netlify build, so it covers dataset reviews and curated examples.
  • NLTK + spaCy spaCy finds the aspect and its opinion word; NLTK VADER scores the opinion.
