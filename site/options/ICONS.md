# Icons used in the design options

All icons are hand-drawn inline SVG in a Lucide-like rounded line style (24x24 viewBox, `stroke="currentColor"`, 1.9px stroke,
round caps and joins). They are original path data written for this project, not copied from SF Symbols or any Apple asset, and
there are no Apple logos. Every icon is decorative (`aria-hidden="true"`) next to a visible text label.

| Destination | Drawing | Style reference (not copied) |
|---|---|---|
| Dashboard | four rounded rectangles in a grid | Lucide `layout-dashboard` (ISC) |
| Reviews & examples | speech bubble with two text lines | Lucide `message-square-text` (ISC) |
| Analyze | pencil | Lucide `pencil-line` (ISC) |
| About | circle with an "i" | Lucide `info` (ISC) |

Self-hosted inline in each option's `index.html`; no icon CDN, no icon font.
