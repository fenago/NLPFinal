Design options for the Dashboard

Three looks for the app's main screen, built from the same real data (/data/*.json), the same NLTK / spaCy badges and the same four destinations: Dashboard, Reviews, Analyze, About. Open each one on a phone-width window (tab bar) and on a wide window (sidebar), in light and dark. The live app is unchanged.

The options

  • Option A: Liquid Glass

    A frosted floating tab bar on phones and a floating sidebar on desktop, over a soft colourful backdrop. Content cards stay solid.

    Open A

  • Option B: Clean Apple Light

    Solid white cards on a light grouped background. Glass only on the bottom tab bar; the desktop sidebar is solid.

    Open B

  • Option C: Dark Pro

    Dark by default, macOS style: a dark glass sidebar, dark grouped surfaces and vibrant accents. A light palette appears only if the system asks for light.

    Open C
