Which library made each result?

  • NLTK Tokenizing, VADER sentiment, word counts and key phrases. Runs in the Netlify build and live in your browser.
  • spaCy Named entities (people, places, brands, products), noun-chunk aspects and the dependency parse. Runs only in the Netlify build, so it covers dataset reviews and curated examples.
  • NLTK + spaCy spaCy finds the aspect and its opinion word; NLTK VADER scores the opinion.

            About and method

            This site is a static Netlify deployment with no server. At deploy time, the Netlify build runs Python: NLTK and spaCy analyse a sample of real Yelp reviews and write JSON files that this page reads. In your browser, Pyodide runs the same NLTK code for the "Analyze your own review" tab.

            What each library does here

            • NLTK Punkt sentence splitting, Treebank word tokens, English stopwords (negations kept for phrases), VADER sentiment for every review and sentence, FreqDist top words, bigram collocations ranked by likelihood ratio.
            • spaCy en_core_web_sm named entities mapped to people (PERSON), places (GPE, LOC, FAC), brands (ORG) and products (PRODUCT); an EntityRuler with names found in this sample; noun-chunk aspects reduced to lemmas; aspect–opinion pairs from the dependency parse (amod, acomp + nsubj, with neg flipping the opinion).
            • NLTK + spaCy VADER scores each aspect's opinion phrase, and scores each review again with entity names masked so names like "Best Buy" do not count as praise.

            Limits

            • VADER is a general-purpose lexicon (extended with 25 review words such as "bland" and "stale"). It still misses context-dependent words such as "cold", sarcasm and polite complaints, and it over-predicts "positive" on long reviews: it agrees with the star rating for about 61% of this sample.
            • The sample is small (197 reviews) and has no business metadata, so the EntityRuler only knows names that appear in it.
            • spaCy results are not available for text you type, because spaCy cannot run in the browser and the project rules out outside servers.

            Numbers, confusion matrices and error analysis: see reports/evaluation.md in the project repository.
