# Technical Writing (S43)

**Owner:** `technical-writer` · **Shared with:** `orchestrator`, `meta-agent`

- Follow Google developer style: second person, present tense, active voice, sentence-case headings, descriptive link text.
- Structure by purpose (Diátaxis): tutorial (run it), how-to (deploy), reference (data contract), explanation (method, limits).
- Every claim with a number links to `reports/evaluation.md`.
- Reference: knowledge/technical-writer/.
