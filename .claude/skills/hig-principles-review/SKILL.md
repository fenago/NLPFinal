# HIG Principles Review (S53)

**Owner:** `ux-designer-apple-hig` · **Shared with:** `ui-designer-apple-liquid-glass`

For each screen answer, with evidence (screenshot/selector):
1. **Hierarchy** — is the primary task obvious within 3 seconds? One clear title, primary action prominent.
2. **Content first / deference** — does chrome (glass bars, decoration) stay out of the way of the reviews and results?
3. **Consistency** — same component = same look/behaviour; platform conventions (tab bar on phone, sidebar on desktop).
4. **Clarity** — legible text, precise labels, icons with names, no jargon without explanation ("VADER", "compound").
5. **Feedback** — every action shows a response (loading, success, error).
6. **Accessibility** — run the accessibility-audit skill.
Rate each Pass / Minor / Major, cite the HIG note in knowledge/ux-designer-apple-hig/ or knowledge/ui-designer-apple-liquid-glass/.
